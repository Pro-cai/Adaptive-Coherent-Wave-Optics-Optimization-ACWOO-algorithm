# ACWOO Algorithm

Adaptive Coherent Wave Optics Optimization (ACWOO) is a novel global optimization algorithm inspired by wave interference and diffraction effects. It is designed to efficiently handle high-dimensional complex optimization problems.

This algorithm was proposed and validated in the paper:
**"Rapid Inverse Design of Transparent Electromagnetic Shielding Metallic Meshes: A Hybrid Framework Integrating Wave-Optics-Inspired Optimization and Analytical Surrogate Modeling"**

## 💡 Core Innovations

Unlike traditional meta-heuristic algorithms, ACWOO draws direct inspiration from the intensity distribution of Fraunhofer diffraction:

*   **Wave-Optics-Inspired Search:** Simulates the physical behaviors of wave interference and diffraction to perform global searches.
*   **Continuous Coherence Factor:** Introduces a continuously changing coherence factor to control the balance between exploration and exploitation.
*   **Fringe-Order-Based Step Scaling:** Utilizes fringe orders to dynamically scale the search step, achieving smooth phase transitions and significantly accelerated convergence.

## 🏆 Validation

The algorithm has been extensively validated on the **IEEE CEC public benchmark functions**, demonstrating its superior performance in terms of convergence speed and solution quality compared to standard baselines.
